System Architecture

Engineered for Performance & Zero Leakage

Frontend Tier

Next.js 16 & React 19

Built with Next.js App Router, Tailwind CSS, and Shadcn UI components for instant rendering, smooth transitions, and offline capability.

- TypeScript & React 19
- Recharts & Lucide Icons
- Client-side PDF & Excel Generator
Backend Tier

FastAPI & Python 3.11+

High-throughput asynchronous REST API powering secure authentication, automated background scheduling with APScheduler, and transaction normalization.

- SQLite with SQLAlchemy ORM
- JWT Authentication & Bcrypt
- AES-256 Fernet Cryptography
Sync Engine

Woob Bank Connectors

Direct open-source banking integration engine querying European and French financial institutions directly from your IP address without intermediary cloud aggregators.

- Web Outside of Browsers
- Direct TLS Bank Sessions
- Automated Background Polls

Deployment

Run Finly in Under 2 Minutes

Deploy locally or on your home server using Docker Compose or standalone development services.

Production Ready
1. Clone repository & launch containers 
git clone https://github.com/louislefo/Finly.git
cd Finly
docker compose up -d --build
Web Application
http://localhost:3000
API Documentation (Swagger)
http://localhost:8000/docs
Default Admin Credentials: Username: admin | Password: admin. Generated automatically upon first initialization.
1. Backend Setup (FastAPI & Python 3.11+) 
cd backend
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000
2. Frontend Setup (Next.js 16) 
cd finly-app
npm install
npm run dev
